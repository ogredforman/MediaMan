# Code map

A short orientation to the code, so a task can start without reading whole packages. Read this
first, then open only the files you'll change or call. Keep it current: when a task adds a
package, a public entry point, or a test fixture, update the matching line here in the same commit.
Signatures here are summaries; `grep -n "public " <file>` (C#) or `grep -n "export " <file>` (TS) gives the exact ones.

## Reading the docs cheaply

- SPEC sections by heading: `awk '/^### 7.1/,/^### 7.2/' docs/SPEC.md` (or `/^## 7\./,/^## 8\./` for a whole section).
  §5 principles, §6.1 entities, §7 core flows, §9 non-functional, §10.2 layout, §10.3 interfaces, §10.4 fakes, §11 UI, §12 testing.
- PLAN: `grep -n '\[ \]' docs/PLAN.md | head` for the next tasks; read only the current stage's section.
- ADRs: 0001 server test stack (xUnit v3, MTP, AwesomeAssertions) · 0002 UUIDv7 ids, Playable/Artwork owner FKs ·
  0003 SQLite conventions and secrets at rest · 0004 web stack and Orval codegen · 0005 desktop build with plain tsc · 0006 TMDB ids carry the kind (`tmdb:movie/603`, `tmdb:tv/1396`) and the shipped token · 0007 artwork cache, `IImageDownloader`, StbImageSharp · 0008 per-install key, HKDF subkeys, Argon2id, Superadmin guard, tokens, signed artwork URLs.
- Area rules: `.claude/rules/<area>.md` (contracts, data, desktop, library, server, server-tests, web).

## Wiring

- **Server:** `server/src/MediaMan.Server/Program.cs` → `AddMediaManServer(config)` (binds `MediaManOptions` from the
  `MediaMan` section, `IClock`→`SystemClock`, `EventBroadcaster`, `IMetadataProvider`→`TmdbMetadataProvider` (`MediaMan:Metadata:Tmdb`, cache in `<DataDirectory>/cache/tmdb`), `IImageDownloader`→`HttpImageDownloader`, `ArtworkCache` (scoped, `<DataDirectory>/cache/artwork`), `MediaManDbContext` on `<DataDirectory>/mediaman.db`,
  ProblemDetails, JSON omits nulls, `LibraryQueries` (scoped), the scan pipeline (`LibraryScanner`/`LibraryMatcher`/`MetadataImporter` scoped via factories, `ScanCoordinator`, `ScanWorker` hosted service), `InstallKey` (`<DataDirectory>/mediaman.key`) → `ISecretProtector`→`AesGcmSecretProtector` on its `secrets-at-rest` subkey, `AccessTokens` on its `access-tokens` subkey, `UrlSigner` on its `artwork-urls` subkey, `PasswordHasher`, `AccountService`, `SessionService` and `ProfileService` (scoped), `LibraryService` (scoped), JwtBearer on `AccessTokens.ValidationParameters`, `SetupState`, `SetupService` (scoped), `AddMediaManBinding()` for the Kestrel listen addresses, `DatabaseMigrator` hosted service) → `UseMediaManErrors()` → `UseLocalNetworkGuard()` → `UseSetupGate()` → `UseMediaManAuth()` (authentication, then `PermissionEnforcement`) → `MapMediaManEndpoints()` (`GET /health`, `POST /setup`, `PUT /server/mode`, `POST /auth/login`, `/auth/refresh` and `/auth/logout`, `/profiles` and `PUT /auth/session/profile`, `GET /events` SSE, library management, browse and scanning, `GET /artwork/{artworkId}`). All in `Hosting/ServerSetup.cs`.
- **Dev configuration** (SPEC §8 setup [P], Debug builds only): running it on the owner's machine (library, ffprobe and MPV paths, launch commands): `docs/LOCAL-DEV.md`. `ASPNETCORE_ENVIRONMENT=Development` + `MediaMan:Dev:MediaPath`
  (user-secrets or `MediaMan__Dev__MediaPath`) → `Dev/DevConfiguration.AddMediaManDev` registers fakes per `MediaMan:Dev:Providers:*`
  (`Fake|Real`) and `DevLibrarySeeder` adds the folder as an External library once. `Dev/DevAccountSeeder` makes sure a Superadmin exists (stored, or `dev` with a random password) and records it in `DevAccount`; `MediaMan:Dev:AutoSignIn` treats token-less requests as it, in a session of its own (`DevAccount.SessionId`, reused across restarts) so it can pick a profile. `MediaMan:Dev:Seed=false` skips both seeders, so the server starts un-set-up (the web server e2e runs setup this way). Dev-only play (SPEC §13): `Dev/DevPlayEndpoints` (`POST /dev/playables/{playableId}/play`, `PickVersion`, `x-dev-only` in the contract) is mapped only when the dev configuration registers `IDevPlayer` (`MpvDevPlayer` via `MediaMan:Tools:MpvPath`, or `FakeDevPlayer` with `Providers:Player=Fake`). The server csproj references `MediaMan.Fakes` in Debug only.
- **Contract:** `contracts/openapi.yaml` (OpenAPI 3.1, `x-permission` per operation) → `npm run generate -w web` (Orval) →
  `web/src/api/*` (client, schemas, MSW handlers, faker). Never edit generated files.
- **Web:** `web/src/main.tsx` → MSW in mock mode (`npm run dev:mock -w web`) → TanStack Router (`router.ts`, file routes in `routes/`) + Query → `AppShell`.
- **Desktop:** `desktop/src/main/index.ts` → one `BrowserWindow` loading `MEDIAMAN_UI_URL` (default `http://localhost:5173`), sandboxed, preload `src/preload/index.cts`.
- **Root scripts:** `package.json` runs server (dotnet), then `web` and `desktop` npm workspaces for `build`, `test`, `lint`.
- **CI:** `.github/workflows/ci.yml` runs `npm ci`, build, a generated-code drift check, lint and test on ubuntu-latest and windows-latest.

## Packages / modules

Server projects live in `server/src/`; most are empty shells until their stage.

- **MediaMan.Core**: domain entities (`Domain/*.cs`, SPEC §6.1), every §10.3 interface (`Modules/Metadata.cs`, `MediaTools.cs`,
  `Indexers.cs`, `Torrents.cs`), `IClock`/`SystemClock`, `ExternalId`, `InfoHash`, `Ids` (UUIDv7), `Permissions` constants.
- **MediaMan.Data**: `MediaManDbContext`, entity config in `Model/*Model.cs`, `MediaManDb.Configure/CreateOptions` (SQLite, WAL via
  `SqlitePragmaInterceptor`), `ISecretProtector`/`AesGcmSecretProtector`, `SuperadminGuard` (SaveChanges interceptor on every context: the stored Superadmin can't be deleted, demoted, disabled or re-roled → `SuperadminProtectedException`), migrations in `Migrations/`.
- **MediaMan.Server**: host and endpoints. `Endpoints/HealthEndpoints.cs`, `Endpoints/AuthEndpoints.cs` (login, refresh, logout), `Endpoints/ProfileEndpoints.cs` (`/profiles` CRUD, `PUT /auth/session/profile`; DTOs alongside), `RequiresPermission(...)` in `Endpoints/PermissionMetadata.cs` (plus `AllowsSignedUrl()`: a valid `UrlSigner` signature stands in for a token),
  `Endpoints/PermissionEnforcement` (middleware: 401 `auth.required`/`auth.session_expired`, 403 `auth.forbidden`; sets the `CurrentUser` feature, with the session's picked `ProfileId`),
  `Hosting/ServerBinding` (`Plan(ServerOptions, recordedMode?)` → `ListenPlan`: the one place for listen addresses and scheme; `MediaMan:Server:Mode` `Local`|`Server`, `Port` default 8420; `ASPNETCORE_URLS` is ignored), `Hosting/LocalNetworkGuard` (middleware: 403 `remote_access.disabled` for non-local, unknown or forwarded clients) over `Hosting/LocalNetwork.IsLocal(ip)`,
  `Hosting/ServerModes` (singleton: the `server.mode` Setting read at startup overrides config; `Active`, `RecordedAtStartup`, static `RecordAsync`), `Hosting/SetupGate` (middleware: 423 `setup.required` until a Superadmin exists; `SetupState` cache + lock; routes opt out with `AllowedBeforeSetup()`),
  `Setup/SetupEndpoints` (`POST /setup`, `PUT /server/mode`) over `Setup/SetupService.CompleteAsync` (field-keyed validation, one transaction: Superadmin, mode, External library, session; queues the first scan),
  `Events/EventBroadcaster` (`Publish`, `Subscribe`) + `EventEnvelope`, `Hosting/Problems.cs` (error model; `Problems.Result(status, code, title, detail, action)` for specific codes).
  `LibraryApi/`: `LibraryEndpoints` (`GET`/`POST /libraries`, `GET`/`PATCH`/`DELETE /libraries/{libraryId}` (delete needs `server.control`), `POST /libraries/{libraryId}/scan`, `GET /libraries/{libraryId}/attention`, `/titles`, `/titles/{titleId}`), `LibraryQueries` (read-only EF queries → DTOs in `LibraryDtos.cs`),
  `LibraryService` (`CreateAsync`, `UpdateAsync`, `DeleteAsync` → `LibraryOutcome`/`LibraryFailure`: field-keyed errors, rows only, queues scans; `DefaultScanIntervalMinutes`), `LibraryRoots` (`PathProblem`, `DataDirectoryProblem`, `Overlap`, `IsUnder`, `NameOf`; case-insensitive except on Linux; shared with setup),
  `Paging.TryRead/Page` (opaque offset cursor, `pagination.invalid`), `Wire.Name/TryParse` (domain enums ↔ contract camelCase strings).
  `ArtworkEndpoints` (`GET /artwork/{artworkId}` serves `ArtworkCache.GetAsync`, fetching on demand; `UrlOf(id)` is the path, `signer.SignedUrlOf(id)` the signed `ArtworkRef.url` every DTO carries).
  `Scanning/`: `ScanCoordinator` (singleton: in-memory scan state per library, `Request` queues once, `TryForget` drops a queued scan (false while running), the worker skips ids no longer queued, publishes `scan.progress`, `IsAvailable` needs `IMetadataProvider`+`IMediaProbe`) and `ScanWorker` (runs scan → match → import → artwork one library at a time, a DI scope per phase).
- **MediaMan.Parsing**: `ReleaseParser.Parse(fileName, parentDirs)` (pure; `parentDirs` outermost first) → `ParsedRelease`, including quality tags with canonical values (`_sources`, `_codecs`, `_hdrFormats`, `_audio` tables) and anime absolute numbers.
- **MediaMan.Playback**: `Probing/FfprobeMediaProbe` (real `IMediaProbe`, runs ffprobe as a process; `FfprobeOptions` path + timeout) and
  `Probing/FfprobeOutputParser.Parse(json)` (pure; HDR names match `ReleaseParser`). Dev wiring reads `MediaMan:Tools:FfprobePath`.
- **MediaMan.Library**: `Scanning/LibraryScanner.ScanAsync(libraryId, ct)` → `ScanResult` (enumerate roots, probe + parse new/changed files as `Pending`, unreadable → `NeedsAttention`, missing → `Missing` with `MissingSince`, purge after 30 days); `Scanning/ScanRules` (pure: video extensions, samples, extras folders).
  `Matching/LibraryMatcher.MatchPendingAsync(libraryId, ct)` → `MatchRunResult` (`MatchDecision`s for the importer at ≥ `MatcherOptions.Threshold` with a clear lead; otherwise MatchReview + `NeedsAttention` with `no-match`/`low-confidence`/`ambiguous`; provider errors retried then left `Pending`); `Matching/MatchScorer` and `TitleSimilarity` (pure scoring); `Matching/ProviderSession` (internal: per-run provider cache, retry/backoff, trip).
  `Importing/MetadataImporter.ImportAsync(decisions, ct)` → `ImportResult` (Title by provider id, Seasons holding linked files with full episode lists, one Artwork ref per type per owner, Playables for linked files only, FileLinks with `Part` from 1, file → `Matched`; absolute numbers resolved over seasons > 0; provider errors → stays `Pending`; unknown episode → `NeedsAttention` `episode-not-found`).
  `Images/ArtworkCache` (`CacheMissingAsync` → `ArtworkCacheResult`, `GetAsync(id)` → `ArtworkLookup`; files `<id>.<ext>`, refuses a cache inside an External root), `Images/DominantColor` (pure: `FromImage`, `FromPixels`), `Images/ImageFormats` (`Sniff` by leading bytes, `ContentTypeOf`).
- **MediaMan.Metadata**: `Tmdb/TmdbMetadataProvider` (real `IMetadataProvider`: v3 API with a Bearer token, 7-day on-disk `TmdbResponseCache`, 429 backoff, 404 → `KeyNotFoundException`), `TmdbOptions` (`ShippedAccessToken`), `TmdbIds` (`Create`/`Parse` `movie/N` and `tv/N`). `Images/HttpImageDownloader` (real `IImageDownloader`: http/https only, 20 MB cap, timeouts → `HttpRequestException`).
- **MediaMan.Auth**: `InstallKey` (`LoadOrCreate(path)`, `FromBytes`, `Derive(purpose)` HKDF subkeys, ADR 0008), `PasswordHasher` (Argon2id PHC strings; `Hash`, static `Verify`, `Default`), `AccountService` (`CreateSuperadminAsync` with its default profile, static `PermissionsOf(user, role)`), `ProfileService` (`ListAsync` (creates a missing default), `CreateAsync`, `UpdateAsync`, `DeleteAsync`, `SelectAsync(userId, sessionId, profileId)` → `ProfileResult`/`ProfileFailure`; static `DefaultFor`, `Avatars`), `AccessTokens` (`Issue(userId, sessionId)`, `ValidateAsync`, `ValidationParameters`; 15-min HS256 JWTs with `sub` + `sid`), `SessionService` (`SignInAsync`, `StartAsync(userId, deviceName)`, `RefreshAsync` rotating `<sessionId>.<random>` refresh tokens with reuse → revoke, `RevokeAsync`) → `SignInResult`/`AuthTokens`. `UrlSigner` (`Sign(path)` → `path?exp=…&sig=…`, valid to the next UTC midnight plus a day; `IsValid`).
- **MediaMan.Indexers, .Torrents**: empty, filled from Stage 1 on.

## Frontend

- `web/src/api/`: Orval output from the contract (generated, do not edit). `web/src/lib/http.ts`: `apiFetch` mutator (sends the stored access token, refreshes near expiry and once after `401 auth.required`, signs out on a `401` it can't fix; `{ anonymous: true }` for login and refresh), `ApiError`, `apiUrl`, `withAuth` (async).
- `web/src/lib/sessionProbe.ts`: `probeSession(queryClient, href)` (the signed-in guard: `GET /profiles` under the generated `listProfiles` key, `staleTime: 'static'`; `401` → sign-in, `423 setup.required` → setup; returns the `ProfileList`). `lib/redirect.ts`: `safeRedirect` for `?redirect=`.
- `web/src/lib/session.ts`: tokens in localStorage (`storedTokens`, `storeTokens`, `clearTokens`, `isSignedIn`, `onSessionChange` across tabs) and `refreshSession(stale, exchange)` (single-flight across tabs under a Web Lock or a localStorage lease; `RefreshRejectedError` signs out). `lib/useSession.ts`: `useSignedIn`, `useRedirectOnSignOut`.
- `web/src/lib/events.ts`: `createSseParser` (pure, chunked SSE → `EventEnvelope`s) and `connectEvents({ onEvent, onOpen, signal })` (streams `GET /events` with fetch, reconnects with backoff).
  `web/src/lib/useLiveScanProgress.ts`: root-layout hook applying `scan.progress` to the libraries cache (`applyLibraryUpdate`); a finished scan invalidates `/titles`.
- `web/src/mocks/`: `handlers.ts` (deterministic `mockHealth`, `mockTokens(tag)` (login and refresh answer with them), `mockLibrary` (re-exported), `mockTitles`, `mockTitleDetails` (a 404 for unknown ids), `createEventStream()` SSE handler with `send`, then generated handlers), `libraries.ts` (`mockLibraries`: stateful library store with the server's root rules (absolute, no overlaps), `409` while a scan runs, `get`/`setScan`, `reset` after each test, starts with `mockLibrary`), `profiles.ts` (`mockProfiles`: stateful profile store with the server's rules, `reset` after each test, starts with `mockProfile` picked; `clearPick` on mock login and setup), `browser.ts` (dev mock mode; a Scan click plays a fake scan over SSE), `node.ts` (Vitest).
- `web/src/routes/`: file routes. `__root.tsx` (bare outlet), `sign-in.tsx` (`SignInForm`, same-site `?redirect=`; a login `423` goes to setup), `setup.tsx` (`SetupWizard`, then Home), `profiles.tsx` (`ProfilePicker` outside the shell, same-site `?redirect=`), `_app.tsx` (pathless layout: `AppShell`, live scan progress, `probeSession` in `beforeLoad`, sending a session with no `activeProfileId` to `/profiles`, `useRedirectOnSignOut`) over `_app/index.tsx`, `movies.tsx`, `shows.tsx`, `titles.$titleId.tsx`, `settings.tsx` (Settings layout and section nav; `settings.index.tsx` redirects to Libraries) over `settings.libraries.tsx`; `routeTree.gen.ts` is generated.
- `web/src/components/AppShell.tsx`: themed shell (nav, `ScanStatus`, Switch profile with the session's profile, Sign out with a stored session, server status). `SignInForm.tsx`: username and password sign-in. `ProfilePicker.tsx`: "Who's watching?" (pick → `PUT /auth/session/profile`, updating the probe cache) and manage mode (add, rename, avatar, delete with a confirmation); `AvatarTile` draws a preset avatar from the `--color-avatar-*` tokens. `SetupWizard.tsx`: first-run setup, one step per screen (account, mode, first library) and one `POST /setup`; `setup.invalid` field errors go back to the step that owns the field. `ScanStatus.tsx`: per-library scan state (`ScanStateText`) + `ScanLibraryButton`. `LibrarySettings.tsx`: Settings → Libraries (cards with folders and scan state; add/edit form with several folders, `rootPaths[N]` errors kept on their folder, PATCH sends only changes; delete with a confirmation). `FormField.tsx`: `Field`, `FieldError`, `FieldErrors`; `formClasses.ts`: `inputClass`, `buttonClass`. `PosterGrid.tsx`: paged Movies/Shows grid (`useInfiniteQuery` over `listTitles`), cards link to the detail page. `artworkSrc(ref)` in `lib/http.ts` resolves an `ArtworkRef`. `TitleDetail.tsx`: detail page (tinted hero, versions, season tabs, episode list) over `useGetTitle`, with a prototype `PlayButton` over `useDevPlay`. `web/src/lib/mediaFormat.ts`: `formatDuration`, `formatSize`, `resolutionLabel`, `versionTags`. `web/src/theme/theme.css`: SPEC §11 tokens for Tailwind.
- `desktop/src/main/`: `window.ts` (`resolveUiUrl`, `mainWindowOptions`, navigation guards), `player.ts` (`IPlayer`), `serverProcess.ts` (`IServerProcess`).
- `desktop/mpv/`: `mpv.conf` and `osc.lua` placeholders.

## Tests and fixtures

- One test project per module in `server/tests/MediaMan.<Module>.Tests`; every one references `server/tests/MediaMan.Fakes`:
  `FakeClock` (`Advance`), `FakeMetadataProvider` (fixtures, `FailNext`, `FailNextSeason`, `SearchQueries`/`TitleRequests`/`SeasonRequests`),
  `FakeArtworkProvider` (`Add`), `FakeMediaProbe` (`Map`/`Fail` file-name globs, presets `Hd1080`/`Uhd2160Hdr10`/`DolbyVision`),
  `FakeFileWatcher` (`Raise`), `FakeImageDownloader` (`Serve`/`Fail` by URL part, `Requests`, solid `DefaultColor` otherwise) and `TestImages` (`Solid(hex)`, `Bmp(w, h, pixel)`). Fake tests are in `MediaMan.Core.Tests/Fakes/`.
- `server/tests/fixtures/metadata/tmdb-<id>.json`: 33 provider titles (remakes, same-name shows, specials, anime absolute numbers), copied to `fixtures/metadata` in test output.
- `server/tests/corpus/release-names.json`: parser corpus (`path` with `/`, partial `expected` fields, `baseline` accuracy), copied to `corpus/` in `MediaMan.Parsing.Tests` output; `ReleaseParserCorpusTests` enforces the baseline and lists failing cases.
- `server/tests/fixtures/tmdb/*.json`: recorded TMDB responses (trimmed), served by `MediaMan.Metadata.Tests/Tmdb/StubTmdbHandler` by request path and query.
- `server/tests/fixtures/ffprobe/*.json`: saved ffprobe outputs (1080p MKV, HDR10, Dolby Vision, HLG, cover art), copied to `fixtures/ffprobe` in
  `MediaMan.Playback.Tests` output. `FfprobeMediaProbeIntegrationTests` generates samples with ffmpeg and skips when ffmpeg/ffprobe are absent.
- `MediaMan.Fakes/TempDatabase.cs` (shared by every test project): per-test SQLite file (`CreateMigratedAsync`, `CreateEmpty`, `CreateContext`, `OpenRawConnection`).
- `MediaMan.Server.Tests/MediaManFactory.cs`: in-process host on a per-test temp `DataDirectory`; completes setup by default (`CompleteSetup`, Superadmin `SuperadminUsername`/`SuperadminPassword`); always a `FakeImageDownloader` (`Images`); optional environment and settings, `ConfigureServices` (e.g. inject fakes), `KeepDataDirectory` for restarts; a cheap `PasswordHasher`; requests come from loopback unless they send `RemoteAddressHeader` (an IP or `none`); `CreateSignedInClientAsync(ct)` (every permission), `CreateUserAsync(ct, permissions)` → `TestUser` (with a default profile), `CreateClient(TestUser)`.
- `MediaMan.Server.Tests/PermissionEnforcementTests.cs`: the table-driven permission test over every mapped route, plain and in the dev configuration.
- `MediaMan.Server.Tests/Conformance/ContractDocument.cs`: loads the contract; `AssertConformsAsync(response, ct)` validates a response.
  `ContractCoverageTests` checks routes against contract operations. `DevPlayTests` covers the dev-only play endpoint (Debug only), and `ContractOperation.DevOnly` marks `x-dev-only` operations. `LibraryManagementApiTests` covers library CRUD on temp folders with the scan worker removed, so scan states stay put. `LibraryApiTests` seeds a browse fixture (movies with versions, a multi-episode show). `ScanApiTests` scans a temp placeholder folder end to end on the fakes and follows SSE.
- Web: Vitest + Testing Library with MSW (`src/test/setup.ts`: `findBy*` waits 5 s, tests time out at 15 s; `src/test/renderApp.tsx` renders the whole app at a path); Playwright smoke in `web/e2e/` against the mock dev server; `web/e2e/server/` (`playwright.server.config.ts`) runs browse → detail → Play against the Debug server on fakes, started by `e2e/server/start-server.mjs` on fresh placeholder media in `web/.e2e-server/`, behind Vite proxying `/api/*` (`MEDIAMAN_SERVER_URL` + `VITE_API_BASE_URL=/api`). The server starts un-set-up (`Dev:Seed=false`); the `setup` project (`setup.spec.ts`) runs the wizard, picks the profile and saves the session to `e2e/server/session.ts`'s `sessionFile`, which every other spec starts from. `libraries.spec.ts` adds, renames and deletes the empty `.e2e-server/Extra` folder as a second library.
- Desktop: Vitest next to the code (`*.test.ts`).
- Quick runs: `dotnet test --project server/tests/MediaMan.<Module>.Tests`, `npm run test:unit -w web`, `npm run test:e2e -w web` (both Playwright configs), `npm test -w desktop`.
